سياسة الخصوصية (Privacy Policy)

تاريخ آخر تحديث: سبتمبر 2026

يلتزم تطبيق صندوق العمارة (Sandooq El-Amara) بحماية خصوصية المستخدمين وسرية البيانات المالية الخاصة بالعقارات. توضح هذه السياسة البيانات التي نجمعها وكيفية التعامل معها وحمايتها.

1. البيانات التي يتم جمعها

  • بيانات الحساب: البريد الإلكتروني (عند تسجيل الدخول السحابي الاختياري عبر Google أو Firebase).
  • بيانات إدارة العقار: أرقام الشقق، أسماء الشاغلين، أرقام الهواتف (اختياري)، سجلات التحصيلات الشهرية، والمصروفات.

2. كيفية استخدام البيانات

  • إدارة ومتابعة تحصيل اشتراكات الصيانة وحساب المتأخرات تلقائياً.
  • إنشاء ومشاركة إيصالات السداد والتقارير الشهرية والسنوية مع الملاك والسكان عبر واتساب.
  • المزامنة السحابية الآمنة لتمكين استعادة البيانات عند تغيير الهاتف أو فقدانه.

3. حماية البيانات وعدم المشاركة مع أطراف ثالثة

نحن لا نقوم ببيع أو تأجير أو مشاركة أي بيانات شخصية أو مالية مع أي جهات خارجية أو معلنين. يتم تخزين البيانات محلياً على جهازك، وفي حال تفعيل المزامنة السحابية، تُحفظ مشفرة عبر خوادم Google Firebase الآمنة وفق أعلى معايير الحماية.

4. حذف البيانات (Data Deletion)

يحق للمستخدم حذف كافة بياناته وسجلاته في أي وقت من خلال خيار "حذف الحساب والبيانات" داخل التطبيق، أو عبر صفحة طلب حذف البيانات، أو عبر مراسلتنا بالبريد الإلكتروني.
